# Contexto do Projecto

Antes de qualquer alteração de código neste repositório, lê, por esta ordem:

1. `.cursorrules` — convenções de código e arquitectura (prevalece em 
   caso de conflito com documentação desactualizada)
2. `docs/README.md` — índice e trilhos de leitura
3. `docs/STATUS.md` — estado real de implementação (volátil; nunca 
   confiar sem cruzar com o código)
4. `docs/adr/` — decisões arquitecturais já aceites (ADR-01 a ADR-07)

## Metodologia de Trabalho

Um prompt de `docs/Prompts/` de cada vez, sequencialmente. Reportar o 
resultado antes de avançar para o seguinte. Nunca inventar âmbito não 
solicitado.
